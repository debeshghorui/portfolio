# Database-Design

A collection of database design projects built around real-world use cases such as clinic appointment management, parking systems, fitness coaching platforms, thrift stores, and smart elevator control.

## About

This repository contains multiple database design case studies focused on schema planning, normalization, relationships, and practical SQL-based database modeling.

## Projects Included

- Clinic Appointment and Diagnostics Platform
- Comic-Con Parking System
- Fitness Influencer Coaching Platform
- Instagram Thrift Creator Store
- Smart Elevator Control

## Goals

- Design clean and scalable relational schemas
- Apply normalization principles
- Model real-world business rules with databases
- Support practical SQL implementation

## Topics Covered

- Entity-Relationship modeling
- Primary and foreign keys
- Normalization
- Constraints
- Relationships
- Real-world database design

## Tech Stack

- SQL
- Relational Database Design
- ER Diagrams
- Schema Modeling
